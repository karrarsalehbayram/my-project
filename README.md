# موقع كرار صالح — طريقة التعديل اليدوي

الموقع كله ملف واحد: `index.html`، والصور بمجلد `img/`. ما يحتاج أي برنامج أو تنصيب.

## المجلدات
```
index.html            ← الموقع كامل (النصوص، الألوان، الأعمال، التصميم)
img/karrar.webp       ← صورتك الشخصية المفرّغة
img/works/            ← الصور المصغّرة اللي تبين بالبطاقات (عرض ~640px)
img/works/full/       ← نفس الصور بالحجم الكامل، تفتح بالعارض وبالمعاينة
```

## تشغيله على حاسبتك
افتح `index.html` بالمتصفح (دبل كلك). إذا الصور ما طلعت، شغّل سيرفر بسيط من نفس المجلد:
```
python -m http.server 8000
```
وافتح `http://localhost:8000`.

## وين تعدل؟ (افتح index.html بـ VS Code أو أي محرر نصوص)
كل الإعدادات بأعلى الملف داخل `const CONFIG = {`:

| الشي | ابحث عن |
|---|---|
| الألوان | `colors:` |
| واتساب، الإيميل، إنستغرام، Behance، Pinterest | `social:` |
| أرقام سنوات الخبرة والمشاريع | `counters:` |
| الصورة الشخصية | `portrait:` |
| الأعمال | `projects: [` |
| كل النصوص عربي | `ar: {` داخل `translations` |
| كل النصوص إنكليزي | `en: {` داخل `translations` |
| آراء العملاء | `testimonials:` |

## إضافة عمل جديد
1. صدّر الصورة مرتين بصيغة WebP (أو JPG/PNG):
   - مصغّرة بعرض ~640px داخل `img/works/`
   - كاملة بعرض ~1080px داخل `img/works/full/` وبنفس الاسم
   - استخدم أسماء إنكليزية بدون مسافات، مثل `camp-new-1.webp`.
2. داخل `projects: [` أضف سطر بالقسم المناسب:
```js
{"cat": "campaigns", "src": "img/works/camp-new-1.webp", "full": "img/works/full/camp-new-1.webp",
 "title": {"ar": "عنوان العمل", "en": "Work title"}, "client": {"ar": "اسم الحملة", "en": "Campaign name"}, "size": ""},
```
- `cat`: يا قسم — `social` (سوشيال)، `logos` (شعارات)، `prints` (مطبوعات)، `campaigns` (حملات)، `motion` (موشن).
- للسوشيال أضف `"sub"`: `sports` أو `schools` أو `travel`.
- `size`: حجم البطاقة — `""` عادي، `"xl"` كبيرة، `"wide"` عريضة، `"tall"` طويلة.
- **الحملات**: الأعمال اللي إلها نفس `client` تنعرض سوا بقسم واحد. حملة جديدة = اسم `client` جديد.
- `"featured": true` يخلي العمل يطلع بالمختارات فوق.
- ترتيب الأسطر = ترتيب الظهور بالموقع.

> انتبه للفواصل `,` بين الأسطر والأقواس. إذا الموقع صار فارغ بعد التعديل، غالباً نقصت فاصلة أو قوس. اضغط F12 بالمتصفح وشوف تبويب Console يدلك على السطر.

## تبديل الصورة الشخصية
بدّل `img/karrar.webp` بصورة PNG/WebP مفرّغة الخلفية (بدون خلفية)، بنسبة 3:4 (مثلاً 900×1200)، والشخص بالنص، والجسم ينزل لأسفل الصورة. الجزء السفلي ينقص تلقائياً داخل الدائرة والراس يطلع منها.
